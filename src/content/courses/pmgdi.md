  Design. Develop. Publish Mobile Games.

  The Program in Mobile Game Design & Integration (PMGDI) prepares students to build immersive mobile gaming experiences through game art, asset creation, real-time game engines, and mobile game development workflows. Learn to create engaging 2D and 3D games while mastering industry-standard production pipelines for Android, iOS, and cross-platform game development.

  The mobile gaming industry continues to expand rapidly, creating demand for skilled Game Artists, Mobile Game Developers, Environment Artists, and Technical Artists.

  PMGDI equips students with practical knowledge of game design, character creation, environment development, animation, and real-time game engine integration using Unity and Unreal Engine.

  Students develop professional-quality game assets and playable mobile games while building a portfolio that demonstrates industry-ready skills.
