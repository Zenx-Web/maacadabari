Course Overview

Advanced Game Design & Development

Discover the art and science of game development with MAAC's Advanced Program in Game Design & Integration (APDGI). This comprehensive program is designed to transform your creative vision into playable reality.

Dive deep into the world of game design, mastering industry-standard tools like Unity and Unreal Engine. Learn to create immersive gaming experiences, from concept to execution, with a focus on both technical skills and creative storytelling.

With hands-on projects and expert guidance, you'll be prepared for a successful career in the gaming industry. Join us to turn your passion for games into professional expertise.

Course Content

TERM 1 - Game Art & Design Fundamentals

  • Digital Design
  • Vector Illustrations for Games
  • Sound Editing
  • Game Production & Design Documents
  • 3D Design
  • Introduction to Texturing
  • Character Setup

TERM 2 - Game Art & Design Advanced

  • 3D Modeling
  • PBR Texturing
  • Realtime PBR Texturing
  • CG Lighting
  • Prop & Character Setup
  • 3D Animation
  • Motion Capture Animation
  • Digital Sculpting

TERM 3 - Game Engine

  • Game Theory & Pre-Production
  • Working with Unity Game Engine
  • Unity Game Asset Integration & Level Design Mobile
  • Unity Game Asset Integration & Level Design AAA
  • Unreal Game Engine

TERM 4 - Specialization in Mobile Gaming

  • Mobile Game Theory
  • Mobile Pre-Production & Design Documentation
  • UI/UX for Mobile Game
  • Creating a 3D Mobile Game
  • Creating a First Person Shooter Mobile Game
  • Creating a 2D Casual Mobile Game

TERM 5 - Specialization in PC & Console (4 months)

  • Console Game Theory
  • Console Pre-Production & Design Documentation
  • UI/UX for AAA Game
  • AAA Game Level Design
