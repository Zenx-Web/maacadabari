The Advanced Program in Game Design & Integration (APGDI) is MAAC's comprehensive game development program that prepares students for careers in mobile, PC, console, AR, and VR game development. From concept art and game assets to AAA environments and real-time engines, this course provides end-to-end training in professional game production workflows.

---

# Course Overview

Modern gaming combines creativity, storytelling, programming concepts, 3D art, and real-time technologies.

APGDI introduces students to every major stage of professional game production.

Students begin with digital art fundamentals before progressing into 3D asset creation, level design, animation, game engines, and platform-specific game development.

Throughout the course, learners work with industry-standard tools while developing a production-ready portfolio.
