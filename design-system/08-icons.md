# MAAC Adabari
# Icon System

Version: 1.0

---

# Philosophy

Icons should support content.

They should never replace clear communication.

Icons should feel modern, clean and minimal.

Consistency is more important than variety.

---

# Icon Library

Primary

Lucide React

Secondary

Heroicons

Do not mix multiple icon styles on the same page.

---

# Style

Outlined icons are the default.

Filled icons should only be used for

• Active states

• Notifications

• Status indicators

---

# Hover States

Icons may

Scale slightly

Change color

Rotate subtly (only where appropriate)

Avoid excessive animation.

---

# Accessibility

Decorative icons

aria-hidden="true"

Functional icons

Must include accessible labels.

Never rely solely on icons to communicate meaning.

---

# Performance

Import only the icons that are used.

Avoid loading entire icon libraries.

Use SVG icons instead of images whenever possible.

---

# Claude Code Rules

Use Lucide React as the default icon library.

Maintain consistent stroke width and sizing.

Icons should reinforce hierarchy, not compete with content.

Never mix outlined and filled icons within the same component unless indicating state changes.
