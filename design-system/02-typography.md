# Typography System

Version: 1.0

---

# Philosophy

Typography should communicate confidence, clarity, and creativity.

The website should rely on typography to establish hierarchy rather than excessive colors or decorative elements.

Large headlines, generous spacing, and minimal font variation should define the experience.

# Accessibility

Minimum body text

16px

Maintain at least 1.5 line height.

Do not use all-uppercase for long sentences.

Avoid extremely thin font weights.

Never rely on color alone to communicate meaning.

---

# Claude Code Rules

Always use the typography scale defined here.

Do not invent additional heading sizes.

Use no more than two font families across the website.

Typography should create hierarchy before animations or colors do.

Large headings should have breathing room.

Readable content is always more important than fitting more text on the screen.
