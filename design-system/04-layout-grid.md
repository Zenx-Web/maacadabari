# Layout & Grid System

Version: 1.0

---

# Philosophy

The layout should feel structured without looking rigid.

Every page should have a clear visual rhythm.

Layouts should guide the eye naturally through the content.

Avoid clutter.

Favor whitespace over density.

---

# Design Principles

Every page should follow

Clear hierarchy

↓

Strong focal point

↓

Supporting content

↓

Call to Action

Never present all content with equal visual importance.

# Card Alignment

Cards should always align to the same baseline.

Never allow mismatched heights where avoidable.

Prefer equal-height cards within the same row.

# Layout Consistency

Spacing

Footer

CTA style

Grid rhythm

---

# Do Not

Do not mix multiple grid systems.

Do not randomly change container widths.

Do not create custom layouts for every page.

Do not center every section.

Do not use full-width text blocks.

---

# Claude Code Rules

Always use the predefined containers.

Use the 12-column responsive grid unless explicitly required otherwise.

Keep layouts modular and reusable.

Every new section should fit naturally into the established grid.

Maintain consistent alignment, spacing, and proportions across the entire website.

Layouts should prioritize readability, responsiveness, and visual balance over visual complexity.
