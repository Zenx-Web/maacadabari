# MAAC ADABARI
# Design Principles

Version: 1.0

---

# Objective

The MAAC Adabari website should feel like a premium digital experience rather than a traditional educational institute website.

The website should communicate innovation, creativity, technology and confidence.

Every design decision should reinforce this identity.

---

# Brand Personality

The website should feel

• Premium

• Modern

• Futuristic

• Creative

• Minimal

• Interactive

• Intelligent

• Professional

Never feel

• Cheap

• Template Based

• Corporate Boring

• Overcrowded

• Outdated

---

# User Emotion

Visitors should experience

Curiosity

↓

Excitement

↓

Trust

↓

Inspiration

↓

Confidence

↓

Action

Every page should move users through this emotional journey.

---

# Design Philosophy

Less content.

More impact.

Large typography.

Strong visuals.

Meaningful animations.

Clear hierarchy.

Whitespace is a design element.

Never fill empty space just because it exists.

---

# Visual Language

The interface should combine

Premium Technology

+

Creative Education

+

Luxury Automotive

+

Modern Product Design

The inspiration should come from

Apple

Rivian

Nothing

Stripe

Linear

Framer

Notion

Porsche

Lamborghini

Tesla

Avoid copying any single brand.

Instead combine the best qualities of each.

---

# Interaction Philosophy

Everything should respond.

Cards react.

Buttons react.

Images react.

Background reacts.

Cursor reacts.

Scrolling reveals content naturally.

Nothing should feel static.

---

# Animation Philosophy

Animations should guide attention.

Never animate simply because it looks cool.

Every animation should have a purpose.

Examples

Reveal

Focus

Hierarchy

Feedback

Navigation

Storytelling

---

# Typography Philosophy

Typography should communicate confidence.

Use fewer font sizes.

Use stronger hierarchy.

Avoid decorative fonts.

Readable first.

Beautiful second.

---

# Layout Philosophy

Every section should breathe.

Content should never feel cramped.

Large spacing is preferred over dense layouts.

Use asymmetrical compositions where appropriate.

---

# Image Philosophy

Avoid generic stock photos.

Prefer

Student work

Studio environment

Creative process

High quality renders

Professional mockups

Large immersive visuals

Images should support the story.

---

# AI Philosophy

AI is not a gimmick.

It should appear naturally throughout the experience.

The website should communicate

AI Assisted Learning

Industry Ready Skills

Future Careers

Human Creativity Enhanced by AI

Never imply AI replaces creativity.

---

# Accessibility

Design for everyone.

Maintain strong color contrast.

Readable typography.

Keyboard accessibility.

Screen reader compatibility.

Motion reduction support.

Visible focus indicators.

---

# Performance Philosophy

Fast websites feel premium.

Prioritize

Fast loading

Optimized images

Lazy loading

Minimal JavaScript

Efficient animations

Smooth scrolling

Responsive rendering

Every interaction should feel immediate.

---

# Mobile Philosophy

Design mobile first.

Do not remove content.

Reorganize it.

Every interaction should feel natural on touch devices.

---

# Claude Code Rules

When generating UI

Always prefer

Consistency over novelty.

Clarity over complexity.

Performance over decoration.

Accessibility over aesthetics.

User experience over visual effects.

Never generate components that conflict with these principles.

This document overrides any visual decision made elsewhere unless explicitly instructed otherwise.
