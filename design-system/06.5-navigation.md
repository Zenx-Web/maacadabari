# MAAC Adabari
# Navigation System

Version: 1.0

---

# Philosophy

Navigation should feel invisible.

Users should always know

• where they are

• where they can go

• how to get back

The navigation should never become the center of attention.

It should support the experience.

---

# Objectives

The navigation should

• feel premium

• remain lightweight

• respond instantly

• support desktop and mobile equally

• always expose the primary CTA

---

# Performance

Navigation must remain responsive.

Avoid layout shifts.

Preload logo.

Lazy load mega menu content if required.

---

# Accessibility

Keyboard navigation required.

Visible focus indicators.

Escape closes mobile menu.

Arrow keys navigate mega menu.

ARIA labels required.

Overlay traps focus until closed.

---

# Claude Code Rules

Use the same navigation on every page.

Do not create page-specific navbars.

The primary CTA must remain visible on desktop.

Keep interactions subtle and fast.

Navigation should reinforce trust through consistency.
