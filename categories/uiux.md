# What is UI/UX Design?

UI (User Interface) Design focuses on creating visually appealing and interactive interfaces.

UX (User Experience) Design focuses on understanding users, solving problems, improving usability, and creating seamless digital experiences.

Together they create products that are intuitive, accessible, and enjoyable.

UI/UX is used in

• Websites

• Mobile Applications

• SaaS Platforms

• FinTech

• Healthcare

• E-commerce

• OTT Platforms

• Smart Devices

• Automotive Systems

• Enterprise Software
