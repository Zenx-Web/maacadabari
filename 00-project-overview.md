# MAAC ADABARI WEBSITE

Version: 2026

---

# Project Goal

Develop a premium AI-first website for MAAC Adabari.

This is the newest MAAC center in Assam and should represent the future of creative education rather than a traditional training institute.

The experience should feel closer to a technology company than an educational website.

The website must communicate that students are learning:

- Artificial Intelligence
- Animation
- Visual Effects
- Gaming
- Digital Design
- UI/UX
- Content Creation

while preparing them for both employment and the creator economy.

---

# Website Objectives

The website should:

• Generate Admissions
• Build Trust
• Showcase Premium Learning Experience
• Explain Every Course Clearly
• Highlight AI Integration
• Promote CareerX
• Promote CreatorX
• Display Student Work
• Encourage Career Counselling Bookings

# Course Navigation

The Courses page should NOT immediately display every course.

Instead it should present major learning categories.

Example:

Animation

Visual Effects

Digital Design & Content Creation

UI / UX Design

When a visitor selects a category, they should see every course belonging to that category.

Selecting a course opens a dedicated course page.

# Information Hierarchy

Homepage

Purpose:
Inspire visitors and introduce MAAC Adabari.

Purpose:
Help visitors choose a learning category.

Purpose:

# Content Rules

Never invent curriculum.

Never invent software.

Never invent duration.

Always use official brochure information.

Website copy may be rewritten to improve readability while preserving factual accuracy.
