# Homepage Specification

Version: 2026

---

# Purpose

The homepage is the first impression of MAAC Adabari.

Its objective is to:

• Capture attention within the first few seconds.
• Establish MAAC Adabari as a premium AI-powered creative institute.
• Introduce visitors to the creative industry.
• Encourage users to explore courses.
• Generate counselling enquiries.

The homepage should not attempt to explain every course in detail.

Instead, it should inspire curiosity and guide visitors toward the appropriate category.

Display only the primary categories.

Game Design

Digital Filmmaking & Photography

With 7 categories, consider a "View All Categories" or carousel/grid
treatment rather than assuming all 7 fit a single row on desktop -
this is a layout decision for the Learning Categories component, not
a reason to hide any category.

Each category card should contain

Category Name

Short Description

Number of Courses

Explore Button

Do not display complete course details here.

# Homepage Rules

The homepage should introduce.

Category pages should explain.

Course pages should educate.

Avoid duplicating large sections of content across pages.

Every section should encourage users to continue exploring the website.
